# CHUSO 1000 (SAP) 仕様書

このディレクトリには実装（`.sw-net` / Lua）がなく、本書は仮置きの設計メモである。実装との照合は済んでいない。

## 2000系との主な差分

- NITS Simple Bridge を使うため、Control Commands Type 3 と Simple Interface RX を使わない。ただし、2000系とほとんど同じ部分も多い。
- 自車他車締切を使うため、NITS を直接読むマイコンが必要になる。

## ブレーキ

- 非常位置以外では、すべてのブレーキが電磁直通ブレーキの制御下に置かれる。
- 非常ブレーキの信号を受けると、各車が非常管を減圧する。一定時間後に最小限のブレーキが立ち上がる。
