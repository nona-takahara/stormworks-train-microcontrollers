# 車両プローブの composite 結線表（案）

利用者が編集して確定する。チャンネル番号と接続元・接続先の列は仮置きで、
空欄は利用者が埋める。型は [VehicleProbe.md](VehicleProbe.md) に従う。

## 入力 composite（車両 → プローブ）

| 種別 | ch | 内容 | 単位・範囲 | 接続元 |
|---|---|---|---|---|
| number | 1 | 座標 x | m（線路は X 軸方向） | 物理センサComposite直結 |
| number | 2 | 座標 y | m（記録のみ） | 物理センサComposite直結 |
| number | 3 | 座標 z | m（記録のみ） | 物理センサComposite直結 |
| number | 9 | 車両速度 | m/s | 物理センサComposite直結 |
| number | 16 | 実験 Ready | 実験中 ON のまま。OFF で中断。マイコン内部で non-0 / 0 変換 | On/Off→Numerical Swith→Composite Write |
| number | 17 | バッテリー電圧 | 1が最大。おおむね0.9くらいから性能劣化が見られる。電圧と書いているが単位Vではない | Number→Composite Write |
| number | 18〜21 | Slip 1〜4 | 0 / 1（記録のみ。入口が 1 つの整数にまとめる: Slip 1 がビット 0、Slip 4 がビット 3）。Slip 1・2 は同じボギー（2 軸・モーター 1 台）、Slip 3・4 は別のボギー | boolean → Numerical Switch → Composite Write（ポート名 Slip 1〜4） |
| number | 22 | 車軸の回転数 RPS | 補助チャンネルで記録（`6,22,23`） | ポート "Wheel" → Composite Write |
| number | 23 | 時刻合わせののこぎり波（1 tick に 1 ずつ増え、300 tick で一周する。二両編成のみ） | 補助チャンネルで記録（aux2）。両車のプローブで同じ波を読み、記録の時刻を合わせる | マイコン間 composite（ポート "Sync"、マイコンの盤面は 2×6 で (0,5)）の ch1 → Composite Read Number(ch 1) → Composite Write |


以下の2つはハードコードする（`Probe/src/probe_site.lua`。小さい側 -8480、大きい側 480。継続不能になる直前の座標で、余裕は含まない）。

- number | 5 | 限界 x の最小側 | m（線路の限界。プローブが 200 m 内側に自動中断を置く） | |
- number | 6 | 限界 x の最大側 | m（同上） | |


## 物理センサーの出力（ゲームのヘルプ。verified）

| ch | 内容 |
|---|---|
| 1〜3 | x, y, z 座標 |
| 4〜6 | オイラー回転 x, y, z |
| 7〜9 | 線形速度 x, y, z（ch9 を前後の速度として使う。符号付き） |
| 10〜12 | 角速度 x, y, z |
| 13 | 絶対線形速度（符号なし） |
| 14 | 絶対角速度 |
| 15 | local z tilt |
| 16 | local x tilt |
| 17 | 方位（-0.5〜0.5） |

- ch16 と ch17 は、Ready とバッテリーで**上書き**している（local x tilt と方位は使えない）。
- 測定した範囲では、`|ch9| = ch13`（差は最大 0.002 m/s）で、横方向の速度はない。
- ch15（local z tilt）は、この平坦な区間では常に 0。ch4（オイラー回転 x）は、加速とブレーキで
  約 1.54〜1.66 と動く（車体の前後の傾きの変化とみられる。unconfirmed）。
- 入口の補助チャンネル（`6,ch1,ch2`）で、これらの任意の入力チャンネルを `aux1`・`aux2` として記録できる。

## 出力 composite（プローブ → 車両）

| 種別 | ch | 内容 | 範囲 | 接続先 |
|---|---|---|---|---|
| number | 1 | モーター入力 | プローブは飽和させない（±10^6 の上限のみ）。車両の受け付けは -1 〜 +1（負は後退）。測定ツールの取り決めで通常は ±0.4 まで | |
| number | 2 | ブレーキ入力 | プローブは飽和させない（±10^6 の上限のみ）。車両の受け付けは 0 〜 1 | |

## 結線表に載らないもの

- HTTP の通信（実験パラメータの受信、記録の送信）。
- 速度上限（200 km/h = 約 55.6 m/s）。プローブ内に固定する。
- 復帰の向きの判定。開始時に利用者が一時的に操作する間に決める。

## 確認したいこと

- 限界 x の最小・最大を composite 入力（ch 5, 6）で受ける案は未確認である。
  別の受け渡し方にするなら、この表の ch 5, 6 を消す。
- 座標 x は符号付きで、最小側 < 最大側 としてよいか。
