# ク2100形の結果

[MeasurementProcedure.md](../../MeasurementProcedure.md) の手順（`pipeline.py --vehicle ku2100 all`）を一回流した結果。測定は 2026-10-18。
記録は `../data/log_ku2100.csv`、パラメータの正本は `../data/params_ku2100.json`（モデル B は `params_ku2100_freq.json`）。

## 測定の条件

- 発電機がなく、電力無限のチートで測った。バッテリー残量は 1.0 以上として扱った（記録の `batt` は 0.898〜1）。
- この車両は、+モーターで x が減る（`SITE_DIR` の逆）。`data/vehicles/ku2100.json` の `"xdir": -1` で、走行向きの選択を反転した。
  マイコンの `SITE_DIR` は +1 のままで、実行時にコマンド `3,-1` で上書きする（`pipeline.py` が起動時に送る）。
- 速度の上端 `vtop` は 30.5 m/s（モ1800形・モ3000形と同じ値を置いた。inferred）。

## 確認シナリオ（合否）

| 種 | モデル − 実測 rms / 最大 [m/s] | 理想 − 実測 rms / 最大 | 理想 − モデル rms |
|---|---|---|---|
| 92866 | 0.077 / 0.226 | 0.205 / 0.653 | 0.143 |
| 18957 | 0.079 / 0.222 | 0.197 / 0.615 | 0.134 |

合格（rms ≤ 0.12、最大 ≤ 0.35）。モデル B は 0.075 / 0.222 と 0.077 / 0.219 で、A と同等。
誤差が大きい区間は、ブレーキによる減速（理想 − モデルで +0.25〜0.4 m/s）である。先行入力の式の誤差で、他の車両と同じ位置に出る。

## 周波数応答（0.2〜8 Hz）

モデルの |G| は 10% 以内、位相は 10° 以内で、3 Hz まで一致する（振幅 0.06 と 0.12 の両方）。
5 Hz 以上は、モデルのゲインが低く（8 Hz で実測の 0.86 倍）、位相は遅れる（8 Hz で 18°）。

## 確度と未確認

- `Sc`、`muMax`、`v_k` が、当てはめの探索の初期値と一致する丸い値（16.5、19、15.9984）である。探索の範囲に張り付いた可能性がある（unconfirmed）。
- 検証の項目（`validation`）が 0 件（NaN）だった。当てはめの合否は確認シナリオ 2 本で判断している。
- 速度の階段 L1 の当てはめ後、`v_k` が 9.2 から 16.0 へ動いた。高速側の `drop(v)` は、階段の記録に依存する。
