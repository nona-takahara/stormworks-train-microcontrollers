# 共通のモデルと当てはめの手順

モ2000形とモ1800形を、同じモデルと同じ手順（`axle2.mjs`）でモデル化した結果を述べる。
違いは、ログと、そこから決まるパラメータだけである。
モデルは「車輪の回転速度と車体速度の差 `s`」を状態に持つ。`s` は、入力 ch22 の車軸の回転数 RPS から作る。

## モデルの式

車輪の回転速度と車体速度の差 `s` は、入力 ch22 の RPS から作る測定値 `s_meas = π·(RPS − ρ·v)` [m/s] と比べられる状態である
（`ρ` = RPS/v を惰行から推定。名目は 1/(2π·0.5) = 0.3183）。slip の領域（モーター 0.58〜0.6 以上）は、このモデルに含めない。
`F(0) = 1`、`F(1) = 0` は両車で測定した。

遅れ `d_m`、`d_a`、`τ_s` は車両ごとの値（モデル A は階段で決めた値、モデル B は周波数応答で決めた値。後述）。
式の形は A も B も同じである。T = 1/60 s、n は tick、`m`・`b` は記録したモーター指令とブレーキ指令。

### 離散時間（差分方程式。`simulate2` の実装そのもの）

```
u[n]   = m[n − d_m] · F(b[n − d_b])                     F(b) = max(0, 1 − c1·b − (1 − c1)·b²)
σ[n]   = a·σ[n−1] + (1 − a)·Sc·u[n]                     a = τ_s/(1 + τ_s)        車輪の回転速度と車体速度の差 s の状態
D[n]   = clamp( slope · σ[n − d_a] · drop(v[n]), ±muMax )                         駆動の加速度
v[n+1] = v[n] + T·( D[n] − (k + g(b[n − d_b]))·v[n] )
drop(v) = 1 − γ·max(0, |v| − v_k)
g(b)   = 0 (b < 0.0113),   B1·b + B2·b² (b ≥ 0.0113)
```

後退は鏡像（モーターと速度の符号を反転すると同じ式）。ブレーキは絶対値を 1 で頭打ちにする。

### z 領域（ブレーキ 0、速度 v0 での線形の式）

`drop0 = drop(v0)`、`Kd = slope·Sc` とする。

```
Σ(z)/M(z) = Sc · z^{-d_m} · (1 − a)/(1 − a·z^{-1})
D(z)/Σ(z) = slope · drop0 · z^{-d_a}
V(z)/D(z) = T · z^{-1} / (1 − (1 − k_eff·T)·z^{-1})

G(z) = V(z)/M(z) = Kd·drop0·T · (1 − a)/(1 − a·z^{-1}) · z^{-(d_m + d_a + 1)} / (1 − (1 − k_eff·T)·z^{-1})
```

駆動の傾きが速度で下がる分を線形化すると減衰が増える: `k_eff = k + γ·D0/drop0`（`|v0| > v_k` のとき。それ以外は `k_eff = k`）。`D0` はその速度での駆動の加速度。

### s 領域（連続時間への近似）

```
G(s) ≈ Kd·drop0 / (s + k_eff) · e^{−s·L} / (1 + τ_c·s)
L   = (d_m + d_a + 1/2)·T        （1/2 は前進オイラーの積分が持つ半 tick の遅れ）
τ_c = −T / ln a                  （τ_s = 0 なら 0）
```

低周波のゲインは `Kd·drop0/k_eff`、折れ点は `k_eff/2π`（モ3000形で約 0.014 Hz）で、ほぼ積分器にむだ時間がつく形である。

### 遅れの二つの決め方

- モデル A: ステップ入力の当てはめ（下の段階 3a、3a'）が決める値。
- モデル B: `d_m`、`d_a`、`τ_s` を、周波数応答（≤ 20 Hz）のゲイン比の対数と位相差の二乗和が最小になる値にして、他は A と同じにしたもの。
  純粋なむだ時間（`τ_s` = 0、`d_m + d_a` = 5 tick）になり、周波数応答の合わせと階段型データの誤差の両方が A 以下になった（モ3000形。後述）。
  Momelink のようなフィードバックの検討には B を使う。
- 遅れはプローブの経路（出力ノードなど）の遅れを含む。閉ループの評価では、その分を引いて車両単体の値を使う。

## 当てはめの手順（段階。測定した量がそのパラメータを決め、速度は予測として扱う）

| 段階 | 決めるもの | 使うデータ |
|---|---|---|
| 1 | `k` | 入力 0 の惰行の区間（速度 2.5 m/s 超、先頭 24 tick を除く）の `ln|v|` の傾き |
| 2 | `B1`、`B2` | モーター 0、ブレーキ一定（0.0125 以上）の区間の減衰率 − `k`。相対誤差の重み（小さい指令も同じ重み） |
| 3a | `Sc`、`τ_s`、`d_m` | 静止から始まるモーターの階段の窓（プログラム区間 1、ブレーキなし）の、測った `s(t)` |
| 3a' | `d_a` | 同じ窓で、加速度（`dv/dt + k·v`）と、`d_a` tick 遅れた測った `s` の誤差が最小になる値 |
| 3b | `slope`、`γ`、`v_k`、`muMax` | 指令が 40 tick 以上一定の「定常」のサンプルの、駆動の加速度と測った `s`。`slope`・`γ`・`v_k` は、飽和していない領域（`slope·s` < 8）で同時に。`muMax` は残りで |
| 3c | `c1` | モーターとブレーキの同時入力の窓（遅れの後の 24〜56 tick）の駆動（`F` = 駆動 ÷ (`slope·Sc·o_m`)）。`F(1) = 0` に制約 |
| 3d | `d_b` | ブレーキの記録（モーターを切って、ブレーキを 0.05 以上）の、速度の誤差が最小の値 |
| 4 | 微調整 | `Sc`、`τ_s`、`slope`、`k`、`B1`、`B2`、`c1`、`γ`、`v_k` を ±15% の範囲で、当てはめ用の記録の速度の誤差を最小化（`--bound`） |

- 当てはめに使える記録は、過去のすべての記録。`--fit-log` に渡した「あてはめシナリオ」（通常運転の速度域を、加減速度と減速方法を変えて走る。何本でも）は、`γ`・`v_k` と段階 4 に使い、検証から外す。
  「確認シナリオ」の記録（`data/verify_<車両>.csv`）は、どの段階も読まない。確認の結果を見て当て直したときは、その確認シナリオはあてはめ側に移す。
- 当てはめ用の記録は、部品の記録（プログラムの区間が 3 つ以下: 階段、ブレーキの曲線、同時入力、惰行）。
  検証用の記録は、区間が 4 つ以上のプログラム（運転シナリオ、周波数応答、ランカーブ）。
- 高速の駆動の傾きの低下（`γ`、`v_k`）は、部品の記録が約 25 m/s までしかないので、各車の最初のランカーブの走行（巡航で 29〜30 m/s を約 30 秒）と、
  あてはめシナリオを、`γ`・`v_k` の当てはめと段階 4 にだけ使い、検証から外す。
- 傾きの低下の形は、膝を超えた分に比例（べき 1）が、べき 1.5・2 や、速度の表（7 点、段階 4 で調整）より、両車で誤差が小さいか同じだった。表は形の自由度が増えるだけで誤差が減らなかったので採らない。
- 除外の規則（両車に共通）: slip の記録、モーター 0.56 超、速度が 36 m/s を超える記録。
- 最大誤差は、ブレーキ 0.9 以上の急停止の区間を除く（そこは減速が約 60 m/s² で、1 tick の位置合わせが 1 m/s になる）。rms には含める。
- RPS（`s`）が使えるのは、RPS 版の記録だけ。モ2000形は RPS 版の記録（部品 25 本）、モ1800形は 44 本。

### 確認シナリオ（モ1800形。当てはめに使っていない。`data/scenarios/` に計画・プログラム・記録・比較がある）

0 → 35 km/h 10 s → 105 km/h 5 s → 65 km/h 5 s → 90 km/h 5 s → 45 km/h 5 s → 停車。減速度は 0.7〜1.0 m/s² から抽選、減速方法は抽選、
最後は 20〜30 km/h までモーター、そこからブレーキ。誤差は、理想（計画の速度）・モデル（記録した入力を `simulate2` に与える）・実測の三つで比べる。

| 確認 | 理想 − 実測（rms / 最大） | モデル − 実測 | 理想 − モデル |
|---|---|---|---|
| V1（種 89014） | 0.102 / 0.309 m/s | 0.100 / 0.272 | 0.047 / 0.262 |
| V2（種 424） | 0.099 / 0.290 m/s | 0.102 / 0.249 | 0.053 / 0.220 |

- 理想 − モデルが小さいので、先行入力の計算はモデルを正しく逆算している。理想 − 実測の大半はモデル − 実測（モデルの誤差）である。
- 両方の確認で同じ形のバイアスが出た: 105 km/h の保持で実測が −0.24 速く（モデルは遅い）、65 km/h の保持で +0.15（モデルは速い）。
  駆動の傾きの 0.5〜1% の違いに相当し、速度では 0.2 m/s 前後になる（速度は傾きの変化を約 9 s の時定数で増幅する）。
  `s` の応答はモデルと一致している（誤差 0.02 m/s 以内）ので、原因は `s` → 駆動の対応にある（unconfirmed）。
- 「ブレーキ」での減速は、速度が高いと走行抵抗だけで 0.7〜1.0 を超える（7〜9 m/s 以上）ので、モーターが走行抵抗を打ち消し、ブレーキが減速度を担う。
  「モーター減速」は、7〜9 m/s 以上では動力を弱めるだけで、負のモーターは低速（20 km/h 付近以下）でだけ出る。

## 経緯で分かったこと（手順に反映してある）

- 全パラメータを速度だけから同時に当てはめると、`Sc` と `slope` の積しか決まらず、局所解に落ちて、測定から外れた値になる（`Sc` = 10.8、`c1` = 1.22 など）。
  測定した量（`k`、ブレーキの曲線、`s(t)`、`s` と加速度の関係）で先に決め、速度は ±15% の微調整にした。
- 駆動の傾きが高速で下がる（`γ`、`v_k`。1 − γ·v² の形にすると、両車で誤差が大きい。そのため、膝を超えた分に比例する形を用いている）、`s` → 駆動の遅れ `d_a`、ブレーキ 0.9 以上を最大誤差から除く、は、検証の誤差を見て足した。
  `d_a` は、両車で同じ値（2 tick）が、独立に出た。
- `s` の下がり方を、上がり方と別の時定数にする（非対称）と、モ2000形の運転シナリオは良くなったが、周波数応答が悪化した（直流分のずれ）。採らなかった。

## 周波数応答（モ3000形。手順の一部として測る。`freqresp2.mjs`）

モーターを `0.06 + 0.06·sin` で振り、速度 ÷ モーター `G(f)` を、実測とモデル（記録した入力を与えた `simulate2`）で比べた。
各区間は、平均の漂いが成分に漏れないよう、定数・1 次・2 次の項と同時に最小二乗で求める。

| f [Hz] | 0.2 | 0.4 | 0.8 | 1.5 | 3 | 5 | 8 |
|---|---|---|---|---|---|---|---|
| ゲインの比（実測 ÷ モデル） | 1.001 | 0.998 | 0.996 | 0.991 | 0.973 | 0.992 | 1.030 |
| 位相の差（実測 − モデル）[°] | 1.4 | 2.1 | 4.7 | 9.4 | 21 | 36 | 58 |
| 相当するむだ時間 実測 [tick] | 6.1 | 5.9 | 5.8 | 5.7 | 5.6 | 5.6 | 5.5 |
| 相当するむだ時間 モデル [tick] | 7.3 | 6.8 | 6.8 | 6.8 | 6.8 | 6.8 | 6.7 |

- 8 Hz までは、ゲインが 3% 以内で一致する。位相の差は、むだ時間の差約 1.2 tick の直線（1 Hz あたり 7.2°）にほぼ一致し、共振の形（遅れの急な増加）はない。位相の差が 10° 以内なのは 1.5 Hz まで。
- ステップ入力から決めたむだ時間（`d_m` + `d_a` + `τ_s`）が、正弦波の応答の相当するむだ時間より約 1.2 tick 長い（モ2000形でも 4〜5 tick の見え方の差があった）。原因は未確認（unconfirmed）。
  フィードバックの交差周波数が 1.5 Hz より高いなら、位相の評価はこの差を見込む。
- 8〜29 Hz（振幅 2 倍）: 実測の位相は直線のまま（相当するむだ時間 5.4〜5.6 tick）で、遅れの急な増加はない。
  ゲインは、8 Hz の 0.65 から 20 Hz の 0.32 まで下がり、24〜29 Hz は 0.32〜0.33 で平らになる。
  1 tick ごとの離散の積分の形 `Kd/60/(2 sin(π f/60))` との比は、8〜15 Hz で 0.88〜0.89、20 Hz で 0.94、29 Hz で 1.10 であり、20 Hz より上でゲインがこの形より 10〜20% 持ち上がる（原因は未確認）。
  モデルの `s` の一次遅れ（`τ_s` = 0.3 tick）はこの高さを下げるので、実測 ÷ モデルは 20 Hz で 1.4、29 Hz で 1.9 になる。1.5 Hz 以下の用途には影響しない。

## 二つのモデル: ステップ入力で決めた遅れ（A）と、周波数応答で決めた遅れ（B）（モ3000形）

遅れ `d_m`、`d_a`、`τ_s` だけを入れ替えた二つを作る（`fitdelay.mjs <車両> --write`）。他（`Sc`、`slope`、駆動の曲線、ブレーキ）は同じ。
B は、周波数応答（≤ 20 Hz）のゲイン比の対数と位相差の二乗和が最小になる値を、`d_m` 1〜6、`d_a` 0〜4、`τ_s` 0〜1 の格子から選ぶ。

| | `d_m` | `d_a` | `τ_s` | 周波数応答の誤差（≤ 20 Hz / ≤ 8 Hz） | 部品の記録の rms | 確認の rms |
|---|---|---|---|---|---|---|
| A（ステップ入力で決めた遅れ） | 4 | 2 | 0.30 | 1.13 / 0.53 | 0.137 | 0.087 |
| B（周波数応答で決めた遅れ） | 1 | 4 | 0.00 | 0.07 / 0.05 | 0.096 | 0.082 |

- B は、`d_m + d_a` = 5 tick と `τ_s` = 0（純粋なむだ時間）。`d_m` と `d_a` の配分は、周波数応答では決まらない（和が同じなら同じ誤差。`d_m + d_a` = 5 の組はどれも同じ）。
- B は周波数応答を合わせただけでなく、ステップ入力型の記録（部品の記録、確認シナリオ）の誤差も A 以下である。ステップ入力の当てはめ（段階 3a）が選ぶ `d_m`・`τ_s` が、周波数応答と合わない値に寄っていた。
- 確認シナリオ 4 本のモデル − 実測の rms は、A が 0.129・0.108・0.095・0.090、B が 0.099・0.040・0.090・0.085。
- 周波数応答の用途（Momelink の安定性評価）には B を使う。A は、ステップ入力の当てはめの手順をそのまま適用した結果として残す。

## 平衡速度ブロック（単車の同定の拡張。設計のみ・実測待ち）

高速の駆動の低下（`γ`、`v_k`）は、部品の記録が約 25 m/s までで、平衡に達しない保持から決めている。一定のモーターの平衡速度の実験（6 水準）を足し、`Sc`、`k`、`γ`、`v_k`、不感帯を機械が決める手順は [SINGLE_FIT_PLAN.md](SINGLE_FIT_PLAN.md)。

## 未確認・残り

- `d_b`（ブレーキの遅れ）が、モ1800形で 1 tick、モ2000形で 3 tick と違う理由。モーターの遅れ `d_m`・`d_a` は同じなのに違う。
  モーターを切るのと同じ tick でブレーキを入れた記録から決めているので、モーター側の遅れとの区別が不十分かもしれない（unconfirmed）。
- slip の領域はモデルに含めていない。
- 駆動の頭打ち `muMax` は、モ2000形では観測した範囲の上端で、頭打ちが見えていない。
- 仮の許容誤差 0.5 m/s は決定ではない。利用先（Momelink の安定性評価）の精度で決める。
- 部品の記録の数が違う（モ1800形 44 本、モ2000形 25 本）。モ2000形の RPS 版の部品を増やせば、推定のばらつきが減るかもしれない。
