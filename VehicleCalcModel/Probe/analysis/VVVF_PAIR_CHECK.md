# 2000 系牽引制御マイコンの加速度で、二両のモデルと実地を比べる

2000 系の牽引制御マイコン（`CHUSO/CHUSO2000_Traction_Controller/scripts/n485.lua`）を、モ2000形（M 車）とク2100形（T 車）の 1M1T として閉ループで動かし、
その出力の加速度を各車の指令に逆算して、実機へ外部注入する。フォワードモデル（指令 → 速度）と実機の速度の差を見積もる。
測定は 2026-10-18。フォワードモデルは `TWO_CAR_MODEL.md`。確度は verified / inferred / unconfirmed。

## 方法

1. **運転パターン。** 確認シナリオの形: 0 → 35 → 105 → 65 → 90 → 45 km/h → 停止。加速は 0→35 km/h を力行 P2、それ以外を P4。
   制動のノッチは、局面ごとに B20〜B28 を抽選する（`bN/8/3.6` = 0.69〜0.97 m/s²）。停止の最後は B31。
2. **牽引制御マイコンを閉ループで動かす。**
   - `vvvf_harness.lua` が、`n485.lua` を M 車と T 車の二つのインスタンスとして動かす。Momelink（N25、N30、N31、B16 など）は前の tick の値で渡す。
   - `vvvf_closedloop.mjs` が速度を二両のモデルから返す。ノッチは速度で切り替える。
3. **加速度から指令への逆算。** 牽引制御マイコンの出力を、各車が単独で出す加速度として扱う（利用者の指定）。
   - M 車のモーター: `N2`（電動機加速度、符号つき）。M 車のブレーキ: `N1`（摩擦制動減速度）。T 車のブレーキ: T 車の `N1`。T 車のモーターは抵抗相殺だけ。
   - 逆算は毎 tick の厳密な式。抵抗相殺は常に ON。式の二種類（旧の式、新・慣性補完の式 `INERTIA_COMPENSATION_NEW.md`）で指令を作り、同じ種で比べた。
4. **外部注入。** 6 tick ごとの平均を区間にして、各車に 1 本のプログラムとして流す（約 1300 区間、44 KB）。`vvvf_run.py` が両車へ流す。
   6 tick にまとめることの影響は、モデルだけで確かめた: 速度の差は rms 0.0066、最大 0.022 m/s（無視できる）。
5. **採点。** 指令をプログラムの文字列から再構成し（`replay.mjs`）、フォワードモデル（`fwd.mjs` の `THETA1`）で速度を計算して、二両の平均の速度と比べる。

## 結果: モデルと実測の差（`verified`）

パターン全体（約 130 秒、2.2 km、最高速度 29.2 m/s）。種 1〜3 を、旧の式と新の式の二通りの指令で流した（6 本。独立なパターンは 3 本）。

| 実行 | 向き | rms [m/s] | 最大 [m/s] |
|---|---|---|---|
| 種 1（旧の式） | +x | 0.031 | 0.077 |
| 種 2（旧の式） | −x | 0.031 | 0.076 |
| 種 3（旧の式） | +x | 0.031 | 0.079 |
| 種 1（新の式） | +x | 0.029 | 0.074 |
| 種 2（新の式） | −x | 0.032 | 0.076 |
| 種 3（新の式） | −x | 0.032 | 0.077 |

単両の確認の基準（rms ≤ 0.12、最大 ≤ 0.35 m/s）に、余裕で収まる。平衡速度で補正する前（`TWO_CAR_MODEL.md` のレベル 1）は、rms 0.093、最大 0.183 m/s だった。

局面ごと（種 1、新の式。rms / 最大 / 平均 [m/s]）:

| 局面 | 速度 [m/s] | rms | 最大 | 平均 |
|---|---|---|---|---|
| P2 | 0 → 9.7 | 0.013 | 0.029 | −0.010 |
| P4 | 9.7 → 29.3 | 0.037 | 0.074 | −0.032 |
| B25（高速からの最初のブレーキ） | 29.3 → 17.9 | 0.022 | 0.055 | −0.010 |
| P4 | 17.9 → 25.0 | 0.035 | 0.051 | −0.034 |
| B20 | 25.0 → 12.3 | 0.029 | 0.043 | −0.027 |
| B24 | 12.3 → 1.9 | 0.014 | 0.032 | −0.007 |
| B31（停止） | 1.9 → 0 | 0.004 | 0.012 | +0.002 |

- 高速からの最初のブレーキ（B25、B26）の誤差は、rms 0.095〜0.118 から 0.022 に下がった。ブレーキ開始から約 5 秒で +0.02 から +0.13 m/s まで立ち上がっていたランプは、高速での駆動の低下の形（膝の位置）の誤りだった（`verified`。`TWO_CAR_MODEL.md`）。
- 運転パターン 6 本とも、進行方向で見て、モデルのほうが約 0.02 m/s 遅い（−0.022〜−0.019。前進・後退とも同じ向き）。補正の前は +0.02（速い）だった。
- フォワードモデルの残る誤差の詳細は `TWO_CAR_MODEL.md` の「残る誤差」。

## 意図との比較

実現した列車の加速度を、牽引制御マイコンの出力の和に重み 0.5 を掛けた値（意図）と、ブレーキのノッチの減速度 `bN/8/3.6` と比べる（`vvvf_intent.py`、種 1）。

| 局面 | 旧の式の指令: 実測 / 意図 [m/s²] | 差 | 新の式の指令: 実測 / 意図 | 差 | ノッチの減速度 |
|---|---|---|---|---|---|
| P2 | +0.517 / +0.523 | −1.2% | +0.526 / +0.524 | +0.4% | — |
| P4（9.7→29 m/s） | +0.458 / +0.486 | −5.7% | +0.471 / +0.485 | −2.9% | — |
| B25（29→18 m/s） | −0.679 / −0.869 | **+21.8%** | −0.866 / −0.869 | +0.4% | −0.868 |
| B20（25→12 m/s） | −0.678 / −0.697 | +2.6% | −0.673 / −0.697 | +3.5% | −0.694 |
| B24（12→2 m/s） | −0.806 / −0.837 | +3.6% | −0.794 / −0.837 | +5.1% | −0.833 |

- 加速は、`N2` を各車の単独の加速度として渡すと、列車は意図（0.5 × Σ）のとおりに加速する。
- 2 回目の P4（18→25 m/s）の差は、加速度が速度で変わる局面を平均の傾きで比べているため（不具合とは見ていない）。B31（停止の最後）は窓が短く比べられない。

### ブレーキの不感帯（`verified`）

- 旧の式の指令では、B25 の実測が意図に 20% 足りない。原因は、T 車の摩擦ブレーキの要求（`N1(T)` 0.14〜0.6 m/s²）が小さく、必要なブレーキ指令が不感帯（0.0113 未満では効かない）に入り、ブレーキが 0 になること。
- 不感帯のため、単車換算の摩擦ブレーキの要求が `β·B1·0.0113·|v|`（約 `0.024·|v|` m/s²。25 m/s で 0.6）より小さいと、実現できない。
- **フォワードモデルは、この不感帯を表現している**（モデルの減速度 −0.65〜−0.69、実測 −0.679）。不感帯は補償せず、モデルで表現する。
- 新の式の指令は、不感帯に入る要求を同じ車のモーターの負の駆動に回す（制御側の選択。`INERTIA_COMPENSATION_NEW.md`）。モデルの検証の対象ではない。
- 2000 系の牽引制御マイコンは、ブレーキ中に力行を出さない（`n485.lua`: `if bN > 0 then pN = 0 end`）。

## 道具

| ファイル | 内容 |
|---|---|
| `vvvf_harness.lua` | `n485.lua` を M 車と T 車の二つのインスタンスで動かす（1 tick ごとに標準入出力） |
| `vvvf_closedloop.mjs <種> <出力>` | 運転パターンを閉ループで走らせ、指令の時系列（`commands.json`）と区間のプログラム（`programs.json`）を作る（環境変数 `NEWIC=1` で新・慣性補完の式） |
| `vvvf_run.py <種> [区間の tick 数]` | 作った指令を実機へ流す |
| `vvvf_phases.mjs <実行名>` | 局面ごとのモデル − 実測（`fwd.mjs` の旧モデルと記録のモデル） |
| `vvvf_intent.py <実行名>` | 局面ごとの実測の加速度を、牽引制御マイコンの意図とノッチの減速度と比べる |

## 未検証

- 1M1T のみ。M 車を増やした編成、T 車が複数の編成は未検証（`n485.lua` の単位質量の扱いも）。
- 運転パターンの速度は最高 29.2 m/s。単両の `vtop` 30.5 m/s の近く。
- 勾配、曲線、パンタグラフ電圧の低下による力行カット、P2 の定速制御（`cv`）は、パターンに入れていない。
- 回生ブレーキの無効（B18 OFF）、非常ブレーキ、高加速（B2）は流していない。
- 高速からの最初のブレーキの誤差の原因は特定していない。
