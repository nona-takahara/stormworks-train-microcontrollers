# 新・慣性補完の式

目標の加速度から、車のモーターとブレーキの指令を逆算する式。走行抵抗の相殺（`RESISTANCE_CANCEL.md`）と、二両のフォワードモデル（`TWO_CAR_MODEL.md`）にもとづく。
確度は verified / inferred / unconfirmed。測定は 2026-10-18。

## 位置づけ

この文書は、指令を作る側（目標の加速度 → 指令）の式。**目的は、フォワードモデル（指令 → 速度）と実測の誤差を小さくすることで、指令を理想（目標の加速度）に合わせる補正ではない。**
指令の規則の違いは、フォワードモデルの誤差を変えない（下の確認で、どの規則でも rms 0.024〜0.025 m/s）。目標との差は参考値。
ブレーキの不感帯は、補償せずフォワードモデルで表現する。

新旧の差は、**自車のブレーキがモーターの駆動を弱める分の相殺**（`F(b)` で割ること）にある（利用者の整理）。本稿の「旧」は、`F(b)` で割らない形のこと。旧の実装そのものは、このリポジトリにない。

## 要点

- 走行抵抗の相殺は `1.02·(k·|v| + k2·v²)`（二両の 0.5〜29 m/s で、残りが素の抵抗の −0.8〜+0.5%。`RESISTANCE_CANCEL.md`）。
- 駆動の項 `a_m` だけを、高速での駆動の低下 `drop(v)` で割る。相殺の項は割らない。
- 自車のブレーキがモーターを弱める分は、`F(b)` で割って補う。弱まりは `c1·b` の式どおり（相殺のレベルでも。下の直接測定、verified）。
- 補う・補わないの違いは、実現する減速度で ±2〜3% 程度（下の確認）。フォワードモデルの誤差には影響しない。
- ブレーキの要求が不感帯（`b < DZ`）に入る速度では、ブレーキが効かない。この分を同じ車のモーターの負の駆動に回すのは、制御側の選択肢（測定は旧い定数で行ったので、新しい定数では未測定）。

## 記号

車ごとに次の量を持つ。値は `data/params_<車両>.json` と `RESISTANCE_CANCEL.md`。

| 記号 | 意味 | モ2000形 | ク2100形 |
|---|---|---|---|
| `K = Sc·slope` | モーター指令 1 あたりの駆動加速度 [m/s²] | 37.4 | 37.8 |
| `k`, `k2` | 走行抵抗 `k·v + k2·v²`（惰行の当てはめ） | 0.1062, 8e-5 | 0.0939, 8e-5 |
| `B1`, `B2`, `DZ` | ブレーキの効き `g(b) = B1·b + B2·b²`、不感帯 `b < DZ` では効かない | 2.018, 0.163, 0.0113 | 1.979, 0.312, 0.0113 |
| `γ`, `vk` | 高速での駆動の低下 `drop(v) = 1 − γ·max(0, |v| − vk)` | 2.2e-3, 6.9 | 1.7e-3, 16.0 |
| `c1` | ブレーキによるモーターの弱まり `F(b) = 1 − c1·b − (1−c1)·b²` | 1.012 | 0.966 |

## 入力と出力

- 入力: 車が単独で出すべき加速度 `a_m`（モーター分、符号つき。加速が正）、`a_b`（ブレーキ分、減速度、0 以上）、速度 `|v|`。
- 出力: モーター指令 `m`（前進の向きを正）、ブレーキ指令 `b`（0〜1）。

## 式

```
r(v) = 1.02 · (k·|v| + k2·v²)                          走行抵抗の相殺（残す抵抗 0）
x    = a_b / max(|v|, vmin)                            vmin = 2 m/s（二両の連結でも β = 1）
b    = (−B1 + √(B1² + 4·B2·x)) / (2·B2)                ブレーキの逆（B2 = 0 のときは x / B1）。b < DZ なら 0
F(b) = 1 − c1·b − (1 − c1)·b²                          自車のブレーキによるモーターの弱まり
m    = ( a_m / drop(v) + r(v) ) / ( K · F(b) )
```

- `drop(v)` で割るのは駆動の項 `a_m` だけ。相殺 `r(v)` は小さな駆動の領域で `drop` が効かないので割らない。
- 速度 0 では `r(0) = 0`、`a_m = 0` なら `m` = 0（静止中に出力がない）。
- 不感帯の下に入る速度は `|v| > ci/DZ`（`ci = a_b/B1`）。ブレーキは `b = ci/|v|` なので、速度が高いほど小さくなる。

### 編成（二両以上）

- 一つの速度を共有する編成では、列車の加速度は各車の寄与の重み付き和になる（二両は `w` = 0.5 ずつ）。
- 列車の目標加速度 `a` と分担 `s_i`（Σ s_i = 1）に対し、車 i の目標は `a_i = a·s_i / w_i`（質量が等しい二両は `w_i` = 0.5 で 2 倍）。質量が違う編成では、車 A の重み `w_A`（質量の配分）を二両の同定手順が決める（`PAIR_FIT_PLAN.md`。モ1800形 + ク2100形は `w_A` = 0.572）。この文書の確認は、`w` = 0.5 のモ2000形 + ク2100形だけ。
- 単両では `w` = 1。

### 指令の式（マイコンの式 `c0 + c1|v| + c2 v² + ci/|v|` に載せる形）

速度の帯（`vk`、`ci/DZ` の二つの閾値）で区間を分け、帯ごとに係数を固定する。`F(b)` は `1/F ≈ 1 + c1·b`（`b = ci_b/|v|`、`ci_b = a_b/B1`）の一次近似。`a_m'` は `a_m/K`（モーター指令の単位）。

| 項 | 係数（帯ごと） |
|---|---|
| 定数 `c0` | `a_m'`（`|v| > vk` の帯は `a_m'(1 − γ·vk)`）+ `c1·ci_b·k_r`（ブレーキをかける車） |
| `|v|` `c1` | `k_r`（`|v| > vk` の帯は `+ a_m'·γ`）+ `c1·ci_b·q_r`（ブレーキをかける車） |
| `v²` `c2` | `q_r` |
| `1/|v|` `ci` | `c1·ci_b·a_m'`（ブレーキをかける車） |

`k_r = 1.02·k/K`、`q_r = 1.02·k2/K`。ブレーキは別の式 `ci_b/|v|`。`|v| ≤ ci/DZ` の帯だけ有効にする。

## 実機での確認（`verified`）

二両（モ2000形 + ク2100形）。乱択 7 本（最高速度 8〜29 m/s）。実現した加速度・減速度の、目標との差。
規則 v8 は上の式（`F` の補償あり）、v9 は `F` で割らない形。どちらも `w` = 0.5（倍率 2）、`β` = 1。

| 種 | 最高速度 [m/s] | v8 加速度 / 減速度 | v9 加速度 / 減速度 |
|---|---|---|---|
| 501 | 29.0 | −1.1% / −2.4% | −1.1% / +1.0% |
| 502 | 28.6 | −0.1% / −8.3% | −0.1% / −8.1% |
| 401 | 25.1 | +0.3% / −2.2% | +0.3% / +0.5% |
| 201 | 15.8 | −2.3% / −1.4% | −2.3% / +2.0% |
| 203 | 16.1 | −2.3% / −0.9% | −2.2% / +3.8% |
| 103 | 11.0 | −1.4% / −0.8% | −1.8% / +0.5% |
| 301 | 8.1 | −2.0% / −2.5% | −1.7% / −0.8% |
| 平均の絶対値 | | 1.4% / 2.7% | 1.4% / 2.4% |
| モデル − 実測の rms の平均 | | 0.025 m/s | 0.024 m/s |

- 加速度は、どちらも目標より 0〜2.3% 低い。
- 減速度は、`F` の補償あり（v8）が −0.8〜−2.5% で、すこし不足する。補償なし（v9）は −0.8〜+3.8% で、ブレーキの比率が大きい種（203、501）で +1〜+3.8% 高い。
  どちらも ±3〜4% で、差は小さい。補償しないと、ブレーキの比率が大きいほど減速度が高く出る向きは、`F` の弱まりを補償しない分として説明できる（inferred）。
- 種 502 の −8% は、ブレーキの分担が 4% と小さく、ブレーキ指令が不感帯に入って効かなかった分（どちらの規則でも）。モデルはこれを表現している。
- フォワードモデルとの差は、どちらの規則でも同じ水準（rms 0.024〜0.025）。指令の規則によらず、モデルが実機を再現している。

### `F(b)` の直接測定（`f_test.py`、`w` = 0.5、`β` = 1）

相殺のレベルのモーターで、片方の車だけにブレーキをかけ（b = 0.02〜0.08）、ブレーキの式を超える減速度から駆動の弱まり `1 − F` を求めた。

| 車 | b = 0.02 / 0.03 / 0.05 / 0.08 での `(1−F) / (c1·b)` |
|---|---|
| モ2000形 | 0.87 / 1.23 / 0.75 / 0.72 |
| ク2100形 | 1.63 / 1.58 / 0.94 / 1.10 |

比はおおむね 1 で、弱まりは `c1·b` の式どおり。ばらつきは ±0.01 程度の測定の幅による。

## 未解決

- 減速度の目標との差は ±3〜4%。`F` の補償の有無で ±2〜3% 動くが、補償の係数（`c1` の 1 倍。フォワードモデルの記録は `φ` = 1.2 倍だが、`φ` = 1 でも未使用の誤差は下がる。`TWO_CAR_MODEL.md` の「補正の必要性」）の選び方では決まっていない。
- 加速度が目標より 0〜2.3% 低い。遅れと高速での駆動の低下の補正は、この規則に入っていない。
- 相殺で `drop` が効かず、加速では効く理由が分かっていない（フォワードモデルでは、2 両の駆動の低下が始まる速度を 単両の膝より 14.9 m/s 上の値で扱っている。`TWO_CAR_MODEL.md`）。
- ブレーキの不感帯: 単車換算のブレーキ要求が `B1·DZ·|v|`（約 `0.023·|v|` m/s²）より小さいとブレーキは効かない。モーターの負の駆動が使えない車では、時間平均で出す必要がある。
- 二両だけ。単両、三両以上、勾配、曲線は未検証。
