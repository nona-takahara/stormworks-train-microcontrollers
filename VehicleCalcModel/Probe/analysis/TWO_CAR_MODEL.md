# 二両連結のモデル

モ2000形（A、ポート 8765）とク2100形（B、ポート 8766）を連結した状態の、指令 → 速度のフォワードモデル。
同じ形のモデルで、モ1800形 + ク2100形も同定した（「編成ごとの値」。手順は `PAIR_FIT_PLAN.md`）。以下の誤差の表と「補正の必要性」は、モ2000形 + ク2100形の記録（`fwd.mjs` の `THETA2`）についての記述。
指令を作る側（目標の加速度 → 指令）は `INERTIA_COMPENSATION_NEW.md`。測定は 2026-10-18。確度は verified / inferred / unconfirmed。

目的は、フォワードモデルと実測の誤差を小さくすること。指令を理想に合わせる補正は、そのための手段ではない。
ブレーキの不感帯のような特性は、補償せずモデルで表現する。

## 構成（三つのレベル）

| レベル | 内容 | 使う場面 |
|---|---|---|
| 1. 基本 | 連結した列車を、一つの速度を共有する単両のモデルとして扱う。二両のための当てはめはなく、重みは等分（w = 0.5）、ブレーキは単両の式どおり（β = 1） | 列車の平均の速度 |
| 2. 補正 | 駆動と抵抗の側を、組ごとの測定で直す: 駆動の全体の倍率 `eff`、質量の配分 `wA`、抵抗の倍率 `κ`、ブレーキによる駆動の弱まり `φ`、高速での駆動の低下が始まる速度（膝）の単両の値からのずれ `dvk`（など）。ブレーキの不感帯も測定から読む。記録 `THETA2`（モ2000形 + ク2100形）は `eff` と `dvk` だけを直し、`wA` = 0.5、`κ` = `φ` = 1 に固定した版 | 実測に合わせた列車の平均の速度（記録は `fwd.mjs` の `THETA2`） |
| 3. 二質量バネ | 連結器をバネとダンパーにして、各車の速度と車間を別に持つ（`Kc` = 30、`Cc` = 3） | 各車が自車のセンサーで読む速度の過渡（ステップ入力のような急な指令） |

誤差（モデル − 実測、二両の平均の速度。全 139 本、`node fwd.mjs`）:

| 区分 | 本数 | レベル 1 のみ（rms の平均 / 最大） | レベル 2（rms の平均 / 最大） | レベル 2 のバイアスの平均 |
|---|---|---|---|---|
| ステップ入力 | 3 | 0.039 / 0.221 | 0.035 / 0.149 | 0.000 |
| 相殺の保持 | 9 | 0.061 / 0.512 | 0.037 / 0.550 | +0.010 |
| 減速の経路 | 10 | 0.073 / 0.190 | 0.034 / 0.112 | −0.007 |
| 平衡速度、高速の加速、ブレーキ（6 本で当てはめ） | 27 | 0.086 / 0.386 | 0.038 / 0.457 | −0.009 |
| 使用ケース | 16 | 0.068 / 0.164 | 0.029 / 0.152 | −0.008 |
| 乱択の確認 | 68 | 0.087 / 0.220 | 0.025 / 0.107 | +0.002 |
| 2000 系の運転パターン | 6 | 0.093 / 0.183 | 0.031 / 0.079 | −0.001 |

記録 `THETA2` の `eff` と `dvk` は、平衡速度の 6 本（`pf_terminal_*`）だけから決めた。不感帯は、小さなブレーキの 4 本（`pf_brake_dz*`）から読む。ほかの記録は当てはめに使わず、採点にだけ使う。手順の最終版（`PAIR_FIT_PLAN.md`）は、片側駆動の 2 本、惰行、高速加速、相殺ありのブレーキ 3 本も当てはめに使い、`wA`、`κ`、`φ` も当てはめる（「編成ごとの値」）。
レベル 1 のみは、w = 0.5、β = 1 で他の項を単両の値のままにし、2 両の補正も `k2` もない場合。

## 1 両のモデルとのつなぎ

二両のモデルは、単両のモデルを車ごとに 1 つずつ持ち、速度を共有させるだけでできている。単両のパラメータは、二両のために当て直していない。

単両のモデル（`COMMON_MODEL.md`。車輪の回転速度と車体速度の差 `s` を状態に持つ）:

```
u[n] = m[n − d_m] · F(b[n − d_b])
σ[n] = a·σ[n−1] + (1 − a)·Sc·u[n]                a = τ_s/(1 + τ_s)
D[n] = clamp( slope · σ[n − d_a] · drop(v[n]), ±muMax )
v[n+1] = v[n] + T · ( D[n] − (k + g(b[n − d_b])) · v[n] )        T = 1/60 s
```

二両では、この式を車ごとに計算して、次のところだけ変える。

| 項目 | 1 両 | 2 両 |
|---|---|---|
| 速度 | 車の速度 `v` | 一つの `v` を共有（レベル 3 では各車の `v` と連結器のバネ） |
| 駆動 `D_i`、損失 | 単両のパラメータ（`params_<車両>.json`） | 同じ値。高速での駆動の低下、抵抗、ブレーキによる弱まりを測定で直す（レベル 2） |
| 重み | 1 | 各車 0.5（等分） |
| ブレーキの効き | `B1·b + B2·b²` | 同じ（倍率 `β` = 1） |
| モーターの向き | + で +x | ク2100形は + で −x（符号を反転して入れる） |
| 測定 | プローブ 1 台（ポート 8765） | 車ごとにプローブ（8765、8766）。時刻はのこぎり波（300 tick 周期）で合わせる |
| 評価 | 車の速度と比べる | 二両の平均の速度と比べる（レベル 3 は各車と車間） |

- 二両のための当てはめは、重み `w` と `β` を自然な値（0.5、1）に固定しただけ（全部を自由にしても w = 0.4986、β = 0.987 で、成績は同じ。`verified`）。これが、単両のモデルを 2 つ並べるだけで足りるという根拠。
- 抵抗（`κ` = 1、`k2` = 8e-5。惰行の当てはめ）、ブレーキ（`β` = 1）、ブレーキによるモーターの弱まり（`φ` = 1）、高速での駆動の低下の傾き（`λ` = 1）は、単両の値のまま。2 両のために補正する必要はない（`verified`。「補正の必要性」）。
- 記録 `THETA2` で補正するのは、駆動の側の 2 点: 全体の倍率 `eff` = 0.9917 と、駆動の低下が始まる速度（膝）の単両の値からのずれ `dvk` = 14.9 m/s。膝は、モ2000形で 6.9 → 21.8 m/s、ク2100形で 16.0 → 30.9 m/s になる。
  `eff` と `dvk` が 1 両でも効くかは、単両で測り直していない（`unconfirmed`）。単両の確認（rms 0.08〜0.1 m/s）は、2 両の補正の前のパラメータのまま。
- ブレーキの不感帯は、単両の同定の値（0.0113）ではなく、2 両の測定から読んだ 0.0098（範囲 0.009〜0.0105）を使う（「ブレーキの不感帯」）。
- 指令を作る側（目標の加速度 → 指令）は別の式（`INERTIA_COMPENSATION_NEW.md`）。二両では各車の目標を `a/w`（二倍）にして渡す。

## フォワードモデル（レベル 1 と 2）

連結した二両は、一つの速度 `v`（x 軸の向き）を共有する。各車は、単両のモデル（`COMMON_MODEL.md`）の駆動 `D_i` と損失を自車の指令だけで計算し、重み `w` で足す。

```
v' = wA · f_A + (1 − wA) · f_B,    f_i = eff·D_i − (κ·k_i + k2·|v| + β·g_i(b_i)) · v
D_i = sat( slope·sd·drop(v), muMax ),          drop(v) = 1 − γ·max(0, |v| − vk_i − dvk)
g(b) = B1·b + B2·b²   （b < 0.0098 では 0。不感帯）
F(b) = 1 − φ·(c1·b + (1 − c1)·b²)   自車のブレーキがその車のモーターの駆動を弱める
β = 1,  k2 = 8e-5。eff、wA、κ、φ、dvk（と不感帯）は組ごとに手順が決める
記録（THETA2、モ2000形 + ク2100形）: wA = 0.5、eff = 0.9917、κ = 1、φ = 1、dvk = 14.9 m/s
```

`wA` は車 A の質量の配分（2 両の質量が等しければ 0.5）。質量が違う 2 両では、片側だけを駆動したときの見かけの駆動が、質量の比で車ごとに違って見える。

- 単両のパラメータ（`params_mo2000.json`、`params_ku2100.json`）は、二両のために当てはめ直していない。ク2100形は +モーターで x が減るので、モーターの符号を反転して入れる。`γ`、`vk_i` は車ごとの単両の値（`γ`: モ2000形 2.2e-3、ク2100形 1.7e-3。`vk`: 6.9、16.0 m/s）。
- 実装は `fwd.mjs`（記録）。`eff`、`dvk`、不感帯は `pair_loop.mjs` が実験から決める（`PAIR_FIT_PLAN.md`）。

### 当てはめの方法

- 指令は、プローブに送ったプログラムの文字列から再構成する（`replay.mjs`）。プローブのログの motor・brake は小数第 3 位で丸められており、小さな指令（相殺 0.001〜0.08、不感帯 0.0098 付近のブレーキ）の大きさと不感帯の判定が狂うため。再構成した値とログの差は、丸めの範囲（0.0005）に収まる。
- 速度は、二両の平均の速度と比べる（連結器の揺れを避けるため）。
- 記録 `THETA2` の `eff` と `dvk` は、一定のモーターを 80 秒かけた平衡速度の実験 6 本（約 7.3 から 30.3 m/s）で当てはめる。駆動の低下の形は、候補の表（線形、膝のずらし、共通の膝、べき乗）から、この 6 本の 1 本抜き交差検証で機械が選ぶ（「補正の必要性」）。
- `w` と `β` は自然な値に固定した（全部を自由にして当てはめても w = 0.4986、β = 0.987 で、成績が変わらない。`verified`）。
- 二両の連結で `w` = 0.49、`β` = 1.05 に見えたのは、フォワードモデルの他の項（相殺の領域の `drop`、走行抵抗、`F`）の不備を吸収していたため、と考える（`inferred`）。

### 係数の読み方

- `eff` = 0.9917: 駆動の全体が約 0.8% 弱い。1 に固定して膝だけ当てはめると未使用の誤差が悪化する（「補正の必要性」）。1 両の `K = Sc·slope` の同定の幅（0.3% 程度）より大きい。2 両特有の効果か、`K` の誤差かは区別できない（`unconfirmed`）。
- `dvk` = 14.9 m/s: 駆動の低下が、単両の見積もりより 15 m/s 高い速度から始まる。低下の傾き `γ` は単両の値のまま使える（`λ` = 1）。モ2000形の膝は 21.8 m/s、ク2100形は 30.9 m/s（常用の上限 30.5 m/s の外）なので、常用域で駆動が低下するのはモ2000形だけになる。
  単両の膝（6.9 と 16 m/s）が低すぎるのか、2 両で変わるのかは、単両の平衡速度で見る（`unconfirmed`）。
- 相殺のレベルの直接測定（`f_test.py`）は、`β` = 1 で計算すると `1 − F` / `c1·b` が 0.7〜1.6 で、おおむね 1。ブレーキによるモーターの弱まりは `c1` の式のとおり。

## 連結器の弾性（レベル 3）

連結器をバネ（`Kc`）とダンパー（`Cc`）でつないだ二つの質量として扱う。各車が自車の速度を持つ。

```
vA' = (f_A − Fc)/M,   vB' = (f_B + Fc)/M,   M = 1/(2w),   Fc = Kc·(d − d0) + Cc·d',   d = x_A − x_B
Kc = 30 s⁻²,  Cc = 3 s⁻¹                         （質量あたり）
```

- ステップ入力の 5 本で当てはめた（`Kc` 15〜50、`Cc` 1〜6 を走査）。車間は静止時 30.50 m。
- ステップ入力の立ち上がりで、牽引する車の自車の速度が、列車の平均より先に立ち上がる。二車の速度差は最大 0.44〜0.59 m/s、車間は最大 0.16 m 動く。
  A 車の速度の最大誤差は、剛体で 0.27〜0.36、二質量で 0.10〜0.25 m/s（ステップ入力の 5 本。`eff` と `vkp` の前の値で、測り直していない）。全 139 本では、二質量の最大誤差は A 車 0.555、B 車 0.557、車間 0.046 m（最大は 29 m/s の相殺の保持への移行）。
- 滑らかな指令では、レベル 3 はレベル 2 とほとんど差がない。
- 静止からの発進と牽引する車の入れ替えでは、遊び（力が 0 付近で動かない区間）は見えない（`verified`）。静止中の力の向きの反転と、高速の衝撃は未測定。

## 編成ごとの値

手順の最終版（`PAIR_FIT_PLAN.md`）が出した値。`fwd.mjs` の `THETA2` は、モ2000形 + ク2100形の以前の記録のまま。

| 項目 | モ1800形 + ク2100形 | モ2000形 + ク2100形（手順の最終版） | モ2000形 + ク2100形（記録 `THETA2`） |
|---|---|---|---|
| `wA` | 0.572 | 0.502 | 0.5（固定） |
| `eff` | 0.9955 | 0.9885 | 0.9917 |
| `κ` | 0.989 | 0.995 | 1（固定） |
| `φ` | 1.26 | 1.14 | 1（固定） |
| 駆動の低下の形 | 膝のずれ `dvk` 1.6 m/s | 膝のずれ 12.5 m/s とべき 1.29 | 膝のずれ 14.9 m/s |
| 不感帯 | 0.0098 | 0.0098 | 0.0098 |
| 当てはめに使っていない記録の rms | 0.0491（19 本。20 m/s 以上 0.0537） | 0.0249（112 本。0.0277） | 0.0306（0.0377） |

- 質量の配分は、ゲーム内の質量（1800: 8760、2000: 7382、2100: 7064）の比から出る値（1800 の組 0.554、2000 の組 0.511）と一致しない。1800 の組では 0.572 で、有効な質量の比は 1.34（ゲーム内の比 1.24）。主ボディ以外の重量物を除いても 1.27 倍程度という利用者の見立てがある（`inferred`）。質量は入力にせず、手順が片側駆動の実験から決める。
- 2000 の組は、`wA`、`κ`、`φ` を自由にしても 0.5、0.995、1.14 で、1 に近い。自由にすると、既存の 112 本の rms が 0.0306 から 0.0249 に下がる（`verified`）。
- **`eff`、`κ`、`φ` の効き加減は、サンプルが少なく（組は 2 つ）、不明。** 今の見立て（`inferred`。1800+2100 で補正を減らして、当てはめに使っていない別の 19 本の rms を比べた）: `eff` は 0.99〜1.00 でほぼ 1。単独の改善は 2%（0.0599 → 0.0586）で、膝のずれ `Δv_k` と組で効く（2000+2100 では、`Δv_k` だけを当てはめて `eff` = 1 にすると、既存の記録の rms が 0.031 から 0.071 に悪化）。単両の `K` の同定の誤差を吸収している側面が強い。`κ` は 0.989〜0.995 で、単独で 8% 改善（0.0552）。`φ` は 1.12〜1.27 で、単独では効かず（0.0598）、`κ` と組で効く（`κ`、`φ`：0.0533、5 つすべて：0.0490）。分けるには、単両の平衡速度や惰行を切り離して測ることが要る。組が増えるまでは、3 つとも当てはめる。
- 1800 の組は、誤差の床が高い（自由に当てはめたモデルでも 0.045 前後。2000 の組は 0.03 前後）。理由は確かめていない。29 m/s 付近の平衡速度の差は 0.5% 以内（0.1 m/s）。

## 補正の必要性

記録 `THETA2`（モ2000形 + ク2100形）では、補正が要るのは駆動の側の `eff` と膝のずれ `dvk` の 2 点で、抵抗・ブレーキの項は単両の値で足りた。手順の最終版が自由にした `κ`、`φ`、`wA` も、この組では 0.995、1.14、0.502 と中立に近い。モ1800形 + ク2100形では、`κ` 0.989、`φ` 1.26、`wA` 0.572 の補正が要る（「編成ごとの値」）。

- **抵抗とブレーキ（`κ`、`k2`、`φ`）**: 単両の値（`κ` = 1、`k2` = 8e-5、`φ` = 1）に固定したほうが、5 係数を自由にしたときより、当てはめに使っていない記録の誤差は小さい（運転パターン 0.046 → 0.036、確認 0.041 → 0.035。`verified`）。
  惰行の予測（`pf_coast`、記録 `THETA2` では当てはめず）も 0.022 で、`κ` = 1、`k2` = 8e-5 が 2 両でも成り立つ。
- **高速での駆動の低下の形**: 線形の低下（`vk` を超えた分に比例、`λ` を自由に）は、30 m/s 付近の平衡速度が合わない。5 係数を全記録で自由に当てはめても、`pf_terminal_0.085`（30.3 m/s）の rms は 0.118、バイアスは走る向きによらず「モデルのほうが速い」（`verified`）。
  形の候補は、`λ`（傾き）、`Δv_k`（膝のずらし）、`p`（べき数）の空でない部分集合 7 つと、両車に共通の膝の計 8 つ（`pair_loop.mjs` の `FORMS`）。平衡速度 6 本を、1 本を除いて当てはめ、除いた 1 本を予測する（1 本抜き交差検証）。誤差の平均が最小の形を機械が選ぶ（当てはめた値が探索の境界に張り付く形は選ばない）:

| 低下の形 | 自由な係数 | 1 本抜き交差検証の rms [m/s] |
|---|---|---|
| 傾き `λ` だけ（膝は単両の値） | `eff`、`λ` | 0.0511 |
| **膝を単両の値から上へずらす（`λ` = 1）** | **`eff`、`dvk`** | **0.0286** |
| べき数 `p` だけ | `eff`、`p` | 境界に張り付き（失格） |
| `λ` と膝のずれ | `eff`、`λ`、`dvk` | 0.0339 |
| `λ` とべき数 | `eff`、`λ`、`p` | 0.0312 |
| 膝のずれとべき数 | `eff`、`dvk`、`p` | 0.0299 |
| 三つとも | `eff`、`λ`、`dvk`、`p` | 0.0308 |
| 両車に共通の膝（`λ` = 1） | `eff`、`vkp` | 0.0389 |

  線形が大きく劣り、膝を上げる形が選ばれる。選ばれた形で当てはめた `eff` = 0.9917、`dvk` = 14.9 m/s のモデルは、当てはめに使っていない既存の 112 本で rms 0.0306（旧 5 係数の記録 0.0409）、20 m/s 以上で 0.0377（0.0536）。5 係数を全記録で自由に当てはめたオラクルは 0.0348、0.053（`verified`）。
  形の候補の族は、検討の段階で既存の記録の残差を見て立てたもので、固定。族の中の選択は機械が行い、既存の記録は使わない。機械が選んだ形（膝のずらし）は、先に既存の記録を見て手で選んだ形（共通の膝）とは違う。族を、手選びの 4 つから、部分集合の列挙の 8 つに広げても、選ばれる形は同じだった。表にない形が要る車両は、確認が落ちて検出される（`PAIR_FIT_PLAN.md`）。
- **`eff` が要る**: `eff` = 1 にして膝だけ当てはめると、未使用 112 本の rms が 0.0306 から 0.0705 に悪化する（`verified`）。

## ブレーキの不感帯

2 両の測定から読んだ不感帯は 0.0098（範囲 0.009〜0.0105）。A 車（モ2000形）と B 車（ク2100形）で範囲が同じ（それぞれ 0.009〜0.0105）。単両の同定の値 0.0113 は誤り。

| ブレーキ指令（A 車だけ、24 m/s から。B 車の 0.0085 と 0.0105 も同じ結果） | 実測 | モデルが一致する境 |
|---|---|---|
| 0.006 | 効かない | 0.007 以上 |
| 0.0085 | 効かない | 0.009 以上 |
| 0.0105 | 効く | 0.0105 以下 |
| 0.0125 | 効く | 0.0125 以下 |

- 境を 0.0113 にすると、0.0105 の実験は rms 1.34 m/s 外れる（実測は効いている）。0.0098 では 0.02〜0.04。
- 単両の同定（`axle.mjs`、`axle2.mjs`、`scenario.py`）の共通の定数 0.0113 は、車種ごとの値ではない。`axle2.mjs` で 0.0113 と 0.0098 を比べると、ク2100形とモ3000形は単両の検証誤差が同じ（区別できない）、モ1800形は 0.0113 のほうが良い（検証の rms 0.130、0.0098 で 0.141）。単両の測定のブレーキ水準（`pipeline.py` の `blevels`）は 0.0125 以上から始まり、境の下側を測っていない（`verified`）。
- 指令の側の式（`INERTIA_COMPENSATION_NEW.md`、`twocar_verify.py` の規則 v7）も 0.0113 を使う。0.0098 に直したときの実現値は未確認。

## 残る誤差

- **高速からの最初のブレーキ**（2000 系の運転パターンの B25）: rms 0.095 → 0.022、最大 0.119 → 0.055 m/s。ブレーキ開始から約 5 秒で +0.02 から +0.13 m/s まで立ち上がっていたランプは、高速での駆動の低下の形（膝）の誤りだった（`verified`）。
- **進行方向のバイアス**: 運転パターンで、進行方向に見てモデルのほうが約 0.02 m/s 遅い（−0.022〜−0.019。前進・後退とも同じ向き）。補正の前は +0.02（速い）だった。向きが反転したので、膝と `eff` の値で動く量と読む（`inferred`）。
- **最大誤差 0.4〜0.55 m/s は、実験の最後の急停止の開始**（29 m/s からブレーキ 0.5 で約 2 秒で止める区間の開始。`cancel_tuned_a`、`cancel_scaled`、`pf_drive_high_onlyB_0.05`）のタイミングの誤差。1〜2 tick のずれが 0.25〜0.5 m/s になる。急停止の区間を除くと、相殺の保持の最大誤差は 0.55 → 0.09 m/s（`verified`）。0.25 m/s を超える記録は、急停止込みで 7 本、除くと 2 本（強いブレーキの単独）。
- **抵抗相殺なし・モーター 0 で、強いブレーキを 1 両だけにかけた減速**（`pf_brake_onlyA_0.08`、`pf_brake_onlyB_0.08`。24 m/s から。報告のみ）: rms 0.165 と 0.139。モデルの減速が実測より約 3% 強い。食い違いは速度に依存する（22→17 m/s で減速度がモデル 3.57、実測 3.46 m/s²。10 m/s 以下では一致）。
  **相殺のモーターを入れると、同じブレーキが合う**（`pf_brake_cancelA_0.08` は rms 0.017、`pf_brake_cancelB_0.08` は 0.045）。ブレーキ曲線ではなく、モーター 0 の条件に固有（`verified`）。高速でモーター 0・抵抗相殺なしは使用に現れない条件なので適用範囲の外（利用者の判断）。原因は未確認。
  試した直し方は、どれも、ほかの記録を悪化させる: ブレーキの倍率 `β`、車ごと・水準ごとの曲線の倍率、力の立ち上がりの遅れ、モーターを下げる方向の遅れ、高速・大指令でだけ効く減衰、力の上限、走行抵抗をブレーキで下げる項 `ρ`（詳細は `PAIR_FIT_PLAN.md`）。
- **相殺の保持と減速の経路**: 補正の前（rms 0.035、0.033）より 0.002〜0.004 悪い。いずれも 5 係数を当てはめに使っていた記録で、いまは使わない。

## 落とし穴

- `campaign.mjs` とプローブの式 `u = c0 + c1·v + …` の `v` は **絶対値**。ク2100形（モーターの符号が逆）の抵抗相殺は、`c1` を **負** にする。
- 二車の指令が同じ向きで釣り合う実験（両車に同じ +モーター）は、動かない。ク2100形は符号を逆にする。
- 後退（−x）では、符号が全て逆になる。実験の道具は、余裕の大きい側へ自動で選ぶ。線路の端（`SITE_HI` = 480）に近づく前に、向きを変える。
- エリア外から戻すジョグは、プローブの向き（`3,dir`）を使う。A は `3,1`、B は `3,-1` を送る。
- プログラムは、1 本の指令で 1300 区間（約 44 KB）まで流せる（`verified`）。区間の最長 tick（`len`）が短いと、遅い加減速の途中で区間が終わる。
