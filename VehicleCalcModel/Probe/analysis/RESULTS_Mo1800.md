# モ1800形の開ループ同定結果

[MeasurementProcedure.md](../../MeasurementProcedure.md) の手順に沿った、モ1800形（モ2000形とは形が違う）の結果。
測定は 2026-10-18。同じプローブの配線で、モーター・ブレーキを直接つないだ。
手順の 1〜10 を測った。モ2000形との比較は [RESULTS.md](RESULTS.md)。
記録は `../data/log_mo1800.csv`（モ2000形は `log_mo2000.csv`。共通のログを、車両ごとに分けた）。

## 結果（手順の 1〜4）

| 項目 | モ1800形 | モ2000形（参考） | 確度 |
|---|---|---|---|
| 向き（+モーターで x が増える） | 増える（`SITE_DIR` = +1 のまま） | 増える | verified |
| モーターの立ち上がりのむだ時間 | 動き出しまで 6 tick | 約 6 tick | verified（2 tick 刻みで判定） |
| `K`（モーターの加速度 / 入力） | 27.4 m/s²（0.05〜0.3 で線形。0.4 で 26.3 に下がる） | 36.69 | verified |
| `k`（走行抵抗） | 0.1072 1/s（惰行の減速率。20.8 → 14.0 m/s） | 0.1079 | verified |
| `B_eff`（ブレーキの効き = (減速率 − k)/指令） | 1.54（指令 0.1）、1.60（0.3）、1.72（0.6）、1.95（1.0） | 約 2.0（不感帯 0.011 未満）〜 2.18 | verified |
| slip | 0.4 までは出ていない | 0.58 以上 | verified（0.4 まで） |

- 走行抵抗の `k` は、2 両でほぼ同じ（0.1072 と 0.1079）。モーターの `K` とブレーキの `B` は、車両ごとに違う。
- `B_eff` はモ2000形より約 20〜25% 小さく、指令が大きいほど増える。モ2000形の曲線（0.1 で 2.02 から 1.0 で 2.18）に比べて、増え方が大きい。
- モーター 0.4 の `K`（26.3）が 0.3 までの 27.4 より約 4% 下がる。slip の境目を測って確かめる（手順の 7）。

## 車軸の回転数（入力 ch22）

利用者が slip の次のチャンネル（ch22）に出した車軸の回転数 RPS を、補助チャンネルで記録した（ch23〜25 は 0）。
車輪の半径は、速度との傾きから 0.5 m（`RPS = v/(2π·0.5)` の係数 0.318）。

| 条件 | RPS − 0.3183·v（余り）[回転/秒] |
|---|---|
| 惰行（入力 0） | +0.002（ほぼ 0） |
| モーター 0.05 / 0.1 / 0.2 / 0.3 / 0.4 | 0.249 / 0.499 / 0.99 / 1.495 / 2.01（= 4.98 × モーター入力。速度によらない） |
| ブレーキ 0.1 / 0.3 / 0.6 / 1.0（惰行から、平均） | +0.085 / +0.175 / +0.394 / +0.712 |

- モーター入力あたりの余りは一定で、加速度は余りの約 5.5 倍（`加速度 = 27.4·入力`、`余り = 4.98·入力`）。
- ブレーキ中も余りは正で、ブレーキが強いほど大きい。符号のない回転数かもしれない（unconfirmed）。
- RPS が駆動力に効いているか（余りと加速度の関係）は、slip の境目の測定で見る。

## モデル（当てはめ）

形は、モ2000形と同じ構造（駆動に一次遅れ）に、モ1800形の曲線を足したもの。`simulate.mjs` の `--vehicle mo1800` が、その曲線を持つ。

`f' = (K·o_m·F(o_b) − f)/τ`、`dv/dt = min(10.7, f − k·v − g(o_b)·v)`（加速の向きだけ。ブレーキの側には上限なし）

| 記号 | 値 |
|---|---|
| `K` | 30.43 m/s² / 単位（立ち上がりを含む窓で測ると 27.4 に見えるが、定常は約 30） |
| `k` | 0.1091 1/s |
| むだ時間 `d` / 一次遅れ `τ` | 2 tick / 6.63 tick（モ2000形は 3 tick / 1.57 tick） |
| `g(o_b)`（ブレーキの減速率 / 速度） | `o_b` < 0.0113 で 0。それ以上で `1.5·o_b + 0.43·o_b²` |
| `F(o_b)`（モーターの駆動の係数） | 表: 0 → 1、0.1 → 0.94、0.3 → 0.75、0.6 → 0.45、0.9 → 0.11、1.0 → 0 |
| 正味の加速度の上限 | 10.7 m/s²（モーター 0.39 以上） |

モ1800 形のモーターは、立ち上がりが遅い（`τ` が約 4 倍）。ブレーキは約 25% 弱い。走行抵抗は同じ。

## 周波数応答（モーターを `0.08 ± 0.08` で 0.2〜8 Hz。run 53、繰り返し run 54、振幅 2 倍 run 55）

- 繰り返し（run 54）は run 53 と、ゲイン比 0.02 以内、位相 0.7° 以内で一致した（verified）。
- 上のモデルとの比（測定 ÷ モデル）: 1 Hz で 1.06、位相 -6.7°。2 Hz で -19°、3 Hz で -36°、5 Hz で -80°、8 Hz で -137°（小信号）。
  振幅を 2 倍にすると、2 Hz で -9°、3 Hz で -19°、5 Hz で -38°。**モ2000形と違い、振幅で位相が変わる**（モ2000形は振幅 2 倍で同じ）。
- 積分器を除いた応答 `|P|`: モ1800形は 1 Hz で 1.11、2 Hz で 0.80、3 Hz で 0.54、5 Hz で 0.30、8 Hz で 0.24 と、約 2.4 Hz で 0.707 を切る
  一次遅れの形（実際の減衰がある）。モ2000形は 5 Hz まで 0.93〜1.2 で、減衰がほぼなく、純粋なむだ時間に見える。
- 1 Hz 以下ではモデルで足りる。2 Hz 以上では、階段入力の当てはめ（`d` = 2、`τ` = 6.6）より、むだ時間が長く（約 4〜5 tick）
  一次遅れが短い（約 3〜4 tick）形が合う。モ2000形と同じく、階段入力と正弦波で遅れの形が違う。理由は未確認。

## ランカーブの再現（慣性補完の模倣、runcurve-planner の同じ試行、前進と後退）

モ2000形と同じ試行（`semi_dn_hokko-takamigaoka_v110`、2936 m、138.2 s）を、モ1800形の同定値で作った入力（慣性補完の模倣）で走らせた。
前向きの項は `o_m = (a_m + k·v)/K`（`k` = 0.1091）に、計画の速度への追従（ゲイン 0.02）。停止は、ブレーキの効き 1.5、
モーターの弱まり `c` = 0.65 で 1 つの式にした（`runcurve_program.py --params`）。前進と後退は、0.1 m/s、0.5 m 以内で一致した。

| 項目 | 前向きの `K` = 30.43（同定値） | `K` = 28.9（高速側に合わせた調整） | （参考）モ2000形 |
|---|---|---|---|
| 速度の最大誤差 / rms | 1.48 / 0.69 m/s | 1.95 / 0.61 m/s | 0.341 / 0.137 m/s |
| 巡航中の速度の誤差（t = 60〜110 s） | -0.35〜-0.46 m/s | -0.10〜-0.13 m/s | -0.08 m/s |
| 停止までの時間（計画 138.2 s） | 136.7 s | 140.6 s | 138.2 s |
| 停止位置 | 69 m 手前（2.3%） | 32 m 行き過ぎ（+1.1%） | 14.5 m 手前（0.5%） |

- 停止の段階の減速度（`K` = 30.43）: 29.5〜26 m/s で 0.97、26〜22 で 0.90、22〜17 で 0.82、17〜12 で 0.77、12〜7 で 0.78、7〜3 で 0.80、3〜1.5 で 0.83（目標 0.80）。
- 高速側（約 0.1 のモーター指令）では、前向きの `K` が約 5% 小さい（約 28.9）と、巡航と停止の始まりが合う。
  一方、中低速（モーター 0.03〜0.05）では 30 台のほうが合い、停止の後半は 28.9 だと減速が足りなくなる。
  前向きの `K` を一律に変えても、両方は合わない。小さいモーター指令の領域で、有効な `K` が指令や速度で変わるように見える
  （unconfirmed。小さい指令の定常の加速度を、指令ごとに測れば確かめられる）。
- 仮の許容誤差 0.5 m/s は、どちらの設定でも満たさない。モ2000形より再現が難しい。

## モ1800専用モデルの候補（車軸の回転数を状態にする）

車軸の回転数 RPS（ch22）から、車輪の外周の速度の余り `s = 2π·0.5·(RPS − v/(2π·0.5))` を作ると、モーターのみの記録の全サンプルで、
駆動の加速度（`加速度 + k·v`）が `s` の 1 本の曲線になった（`s` を 0.5 m/s ごとのビンに分け、各ビンの平均）。

| `s` [m/s] | 0.5 | 1.0 | 1.5 | 2.0 | 3.0 | 4.0 | 4.5 | 6.5 | 9.0 | 11（slip） | 13（slip） | 14.5（slip） |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 駆動の加速度 [m/s²] | 1.18 | 2.12 | 3.01 | 3.45 | 5.66 | 7.23 | 9.10 | 11.45 | 11.64 | 4.97 | 3.16 | 2.13 |

- `s` が約 6.5 m/s までは、傾き約 1.8〜2.1（駆動の加速度 ≈ 2.0·`s`）。それ以上で約 11.7 m/s² に頭打ち。slip の信号が ON になる `s` > 約 9.5 では、`s` が大きいほど下がる。
  先の「正味の加速度の上限 10.7」は、この駆動の頭打ち（約 11.7）から抵抗を引いた値に当たる。slip 中の加速度が入力で変わるのも、同じ曲線で表せる。
- `s` はモーター指令に追随する（定常で 15.65·指令 [m/s]）。立ち上がりの遅れ（`τ` 約 6.6 tick）は、指令 → `s` の一次遅れに当たると見られる。
- 構造の案: `s' = (15.65·o_m·F(o_b) − s)/τ_s`（指令から `s` への遅れ）、`a_drive = μ(s)`（上の曲線を表にする）、
  `dv/dt = a_drive − k·v − g(o_b)·v`。この形なら、頭打ち、slip、立ち上がりの遅れ、高周波の減衰を 1 つの構造で表せる（未検証。上の曲線までは検証済み）。
- ランカーブで見えた「高速側で前向きの `K` が約 5% 小さい」は、指令 → `s` の係数（15.65）が速度で変わるのかもしれない（unconfirmed）。
- RPS を制御側で読めるなら、`a_drive = μ(s)` から駆動の加速度を推定でき、slip の信号を使わずに slip を検出できる。

## 前提と未確認

- 車軸の回転数 RPS の余りは、モーター**指令**に追随する（加速度ではない）。RPS が駆動力にどう効くかは未確認。
- slip の信号は Slip 3・4（2 軸）だけが ON になった。モ1800形が電動機をどの台車に持つかは、結線を確かめていない。
- ブレーキの効き 1.5（不感帯の外、0.0125〜0.05）の推定は、`o_b` が小さいと ±0.1 のばらつきがある。
- むだ時間は、プローブの配線の遅れ（下限 2 tick）を含む。車両単体の値は、モ2000形と同じ扱い。
